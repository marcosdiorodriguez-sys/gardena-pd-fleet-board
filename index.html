Board layout: one card per asset, every overdue/due-soon item listed underneath — decided 2026-09-14 over a flat-row alternative, to mirror Whip Around's own Work Order item grouping. · Due-soon window: 500 mi or 14 days before the next service threshold (placeholder, pending final sign-off). · “Overdue” is read directly from Whip Around's own status field, not recalculated here. · “Scheduled this week” is a separate, date-only view — any pending service with a calendar due-date in the next 7 days, regardless of mileage or overdue/due-soon status. It's usually empty: as of this build, Whip Around only has calendar due-dates set on 16 of the fleet's pending services, and all 16 are a year or more out, so nothing currently falls in this window. The section is built to populate automatically as real near-term dates get entered. · Refreshes automatically about once an hour via a scheduled job on Alex's computer. If the "last pulled" time above looks stale, the job likely missed a run — that machine needs to be on with the Claude app running for the refresh to fire.
